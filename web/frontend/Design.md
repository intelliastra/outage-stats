```
┌────────┐ ┌────────┐ ┌────────┐ ┌────────┐ ┌────────┐ ┌────────┐
```

**字体**

- 标题 / 正文：`Microsoft YaHei`, `PingFang SC`, `Segoe UI`, sans-serif

## 4. 页面 2 — 历史区间统计（`historical.html`）

```
┌─ 参数区 ─────────────────────────────────┐
│ ┌ 统计参数 ───────────────────────────┐ │
│ │ 统计年份  ○ 2025  ○ 2026             │ │
│ │ 起始日期  [月▼] [日▼]                │ │
│ │ 结束日期  [月▼] [日▼]  （允许跨年）  │ │
│ │                                      │ │
│ │ 数据说明（只读信息条）               │ │
│ │  · 2025 → Annual Summary/...xlsx     │ │
│ │  · 2026 → Newdata 最新 Excel         │ │
│ │ 剔除文件：自动使用表11（只读状态）   │ │
│ └─────────────────────────────────────┘ │
│ [ 获取统计 ]  busy 时禁用                │
└──────────────────────────────────────────┘

┌─ 监控区（与日常页同构）──────────────────┐
│ 状态 / 进度条 / 日志 Tab / 结果三件套     │
│ 提示：长时间无日志输出 ≠ 卡死             │
└──────────────────────────────────────────┘
```

**前端校验**

- `end_date >= start_date`（跨年合法，如 2025/12/1–2026/1/15）  
- 数据源 `ready: false` 时禁用「获取统计」并展示原因

## 6. 交互状态

| 状态 | 徽章 | 进度条 | 主按钮 | 结果区 |
|------|------|--------|--------|--------|
| idle | 等待（灰） | 隐藏 | 可用 | 隐藏 |
| running | 运行中（蓝+spinner） | 动画 | 禁用 | 隐藏 |
| success | 成功（绿） | 满条静止 | 可用 | 展开摘要+下载 |
| error | 失败（红） | 隐藏 | 可用 | 展示失败说明 |
| busy-elsewhere | — | — | 禁用+「已有任务运行中」 | — |

SSE 中断时自动降级轮询 `/api/jobs/{id}`（现有逻辑保留）。
